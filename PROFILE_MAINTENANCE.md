# Profile repository maintenance

This repository powers the public GitHub profile README.

## Keeping the profile current

- Keep project links pointing to active public repositories.
- Prefer short descriptions that explain what each project demonstrates.
- Remove stale technologies or claims when a project changes.
- Keep badges and external links working.
- Review the profile after major project launches or repository renames.

## Update checklist

1. Verify repository names and links.
2. Check that featured projects are still public.
3. Confirm technology labels match the current projects.
4. Preview the rendered README before merging.
